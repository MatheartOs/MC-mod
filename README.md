MC Fabric 模组开发实战
基于 Minecraft 1.20.1 / Fabric Loader 的个人模组开发练习项目。

---
📌 项目介绍
本项目为 Minecraft 1.20.1 版本下的 Fabric 模组开发实战项目，以原生 Java + Fabric API 进行开发，从零实践模组各类基础核心功能，用于个人学习与技术积累，项目持续更新迭代。

---
⚙️ 开发环境
- 游戏版本：Minecraft 1.20.1
- 模组加载器：Fabric Loader
- 核心依赖：Fabric API
- 开发语言：Java
- 构建工具：Gradle

---
✅ 已实现功能
- 自定义材质加载：实现方块、物品自定义材质资源加载与渲染
- 方块自定义属性：可自主配置方块硬度、挖掘速度等基础属性
- 自定义掉落概率：支持方块、物品自定义掉落规则与概率控制
- 自定义合成表：实现各类自定义工作台合成配方，支持多样式合成规则
- 实体交互逻辑：开发自定义实体交互事件，拓展原版实体交互行为
- 自定义实体 NBT 标签：支持实体自定义 NBT 数据的写入、读取与存储，实现实体数据持久化
